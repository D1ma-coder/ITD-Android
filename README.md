Нативный клиент соцсети ИТД на Kotlin и Jetpack Compose. В приложении есть лента, чаты, комментарии, уведомления и профиль. Можно менять оформление, настраивать нижнюю панель и переключаться между аккаунтами.

**[Скачать APK](https://github.com/D1ma-coder/ITD-Android/releases/latest) · [Установка](#установка) · [Обновления](#обновления) · [ИТД для Windows и macOS](https://github.com/D1ma-coder/ITD-app/releases)**

## Возможности

| Раздел | Что доступно |
| --- | --- |
| Чаты | Сообщения себе, ответы, пересылка, голосовые, реакции и действия сразу с несколькими чатами или сообщениями |
| Лента | Посты с фото, видео и опросами, комментарии и ветки ответов |
| Профиль | Фотобаннер, полноэкранное рисование баннера и переключение аккаунтов |
| Оформление | Свои темы и обои для чатов, перетаскивание вкладок в настройках навигации |
| Уведомления | Фильтры и системные уведомления для выбранных аккаунтов |

## Установка

Нужен телефон или планшет с Android 8.0 или новее и процессором ARM64.

1. Скачайте файл `ITD-…-Android-arm64.apk` со страницы последнего релиза.
2. Откройте APK на телефоне. Если Android попросит разрешение, включите установку приложений для источника, из которого открыли файл.
3. Если ИТД уже установлен, подтвердите обновление. Удалять установленное приложение перед этим не нужно.

## Обновления

ИТД проверяет релизы в этом репозитории. Автообновление и ручная проверка находятся в разделе **Настройки → Приложение**. Установку скачанного обновления подтверждает Android.

Если у вас установлена прежняя Android-версия ИТД из репозитория для компьютеров, скачайте первый APK из этого репозитория и установите его поверх установленного приложения.
